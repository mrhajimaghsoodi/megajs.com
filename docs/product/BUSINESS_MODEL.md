# Business Model

## Access layers

| Layer | Examples | Goal |
|-------|----------|------|
| Free | Articles, podcasts, lesson previews, limited challenges | SEO + habit |
| Subscription | Ongoing path access, webinars, updates | MRR |
| Paid course | React / Next specialty courses | High intent revenue |
| Tokens | Earned via practice, spent at checkout | Retention + conversion |

## Acquisition priority

1. **SEO** — indexable FA/EN pages for tracks, courses, lessons, articles, live events
2. **Social** — Instagram, YouTube, Aparat clips that canonicalize back to site lessons

## Curriculum monetization timeline

- Year 1 Frontend JS path: primary catalog
- Year 2 Vue/Angular: expand catalog + upsell
- Year 3 RN/Electron: app tracks + desktop/mobile brand proof
- Year 4 Node/Nest: full-stack JS completion + possible all-access membership
