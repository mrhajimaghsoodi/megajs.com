# طراحی واکنش‌گرا

```css
@media (min-width: 768px) {
  .sidebar { display: block; }
}
```

Mobile-first کار کنید. واحدهای سیال (`%`، `rem`، `clamp()`) را با breakpoint ترکیب کنید.
