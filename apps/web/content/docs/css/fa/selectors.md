# سلکتورها

```css
article p { }
.card { }
#hero { }
a:hover { }
button:focus-visible { }
```

برای UI قابل‌استفاده مجدد، class را ترجیح دهید. id را برای landmark یکتا یا hook جاوااسکریپت نگه دارید.
