# Template Literalهای ES6

Template Literalهای ES6 درباره ساخت stringهای خوانا برای label، class name و log است. این درس بازنویسی آموزشی و مستقل از مسیر W3Schools React Tutorial است و مثال‌ها به شکل HTML کامل با React CDN و Babel نوشته شده‌اند تا در live editor اجرا شوند.

در تمرین Template Literalهای ES6 فقط ظاهر UI را نبینید؛ render شدن component، تغییر state، props، warningهای Console و رفتار JSX در DOM را هم بررسی کنید.

## ایده اصلی

- ``Hello ${name}``: value را داخل text interpolate می‌کند.
- `class string`: text محاسبه‌شده برای className.
- `label`: text نمایشی ساخته‌شده از data.
- برای این موضوع، هماهنگی JSX، props، state و behavior قابل مشاهده در UI نشانه اصلی کیفیت React code است.

## مثال‌های HTML قابل اجرا با React

هر مثال یک سند کامل HTML است که react@18، react-dom@18 و @babel/standalone را از CDN load می‌کند. آن را در live editor اجرا کنید و سپس یک state، prop یا JSX branch را تغییر دهید.

## اشتباه‌های رایج

- کپی کردن Template Literalهای ES6 بدون بررسی Console warning، key، dependency array یا update شدن state.
- mutate کردن object یا array در state به جای ساخت copy تازه با spread، map یا filter.
- فراموش کردن تست ``Hello ${name}`` با keyboard، state خالی، StrictMode و browser هدف.
