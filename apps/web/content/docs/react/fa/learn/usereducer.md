# Hook با نام useReducer

Hook با نام useReducer درباره متمرکز کردن transitionهای state پیچیده در reducer است. این درس بازنویسی آموزشی و مستقل از مسیر W3Schools React Tutorial است و مثال‌ها به شکل HTML کامل با React CDN و Babel نوشته شده‌اند تا در live editor اجرا شوند.

در تمرین Hook با نام useReducer فقط ظاهر UI را نبینید؛ render شدن component، تغییر state، props، warningهای Console و رفتار JSX در DOM را هم بررسی کنید.

## ایده اصلی

- `useReducer`: برای transitionهای state از reducer استفاده می‌کند.
- `dispatch`: action را به reducer می‌فرستد.
- `action`: تغییر state را توصیف می‌کند.
- برای این موضوع، هماهنگی JSX، props، state و behavior قابل مشاهده در UI نشانه اصلی کیفیت React code است.

## مثال‌های HTML قابل اجرا با React

هر مثال یک سند کامل HTML است که react@18، react-dom@18 و @babel/standalone را از CDN load می‌کند. آن را در live editor اجرا کنید و سپس یک state، prop یا JSX branch را تغییر دهید.

### مثال 1: الگوی React متمرکز

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>React useReducer Hook</title>
    <script crossorigin src="https://unpkg.com/react@18/umd/react.development.js"></script>
    <script crossorigin src="https://unpkg.com/react-dom@18/umd/react-dom.development.js"></script>
    <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
    <style>
      body { font-family: system-ui, sans-serif; margin: 1.5rem; line-height: 1.5; color: #1f2937; }
      button, input, select, textarea { font: inherit; margin: 0.25rem; }
      .card { border: 1px solid #d1d5db; border-radius: 0.75rem; padding: 1rem; max-width: 34rem; }
      .row { display: flex; flex-wrap: wrap; gap: 0.5rem; align-items: center; }
      .badge { display: inline-block; border-radius: 999px; background: #e0f2fe; color: #075985; padding: 0.15rem 0.5rem; }
      .muted { color: #64748b; }
    </style>
  </head>
  <body>
    <div id="root"></div>
    <div id="modal-root"></div>
    <script type="text/babel">
      const { useState, useEffect, useContext, useMemo, useCallback, useRef, useReducer, useTransition, useDeferredValue, useId, Suspense, StrictMode, Fragment, memo, createContext } = React;
      function reducer(state, action) {
        if (action.type === 'add') return { count: state.count + 1 };
        if (action.type === 'reset') return { count: 0 };
        return state;
      }
      function App() {
        const [state, dispatch] = useReducer(reducer, { count: 0 });
        return (
          <section className="card">
            <h1>React useReducer Hook</h1>
            <button onClick={() => dispatch({ type: 'add' })}>Add</button>
            <button onClick={() => dispatch({ type: 'reset' })}>Reset</button>
            <p>Reducer count: {state.count}</p>
          </section>
        );
      }
      ReactDOM.createRoot(document.getElementById('root')).render(<App />);
    </script>
  </body>
</html>
```

## جدول syntax و کاربرد

| Syntax | کاربرد | نکته authoring |
| --- | --- | --- |
| `useReducer` | برای transitionهای state از reducer استفاده می‌کند | در Hook با نام useReducer آن را با render واقعی، state خالی، interaction و Console تست کنید. |
| `dispatch` | action را به reducer می‌فرستد | در Hook با نام useReducer آن را با render واقعی، state خالی، interaction و Console تست کنید. |
| `action` | تغییر state را توصیف می‌کند | در Hook با نام useReducer آن را با render واقعی، state خالی، interaction و Console تست کنید. |

## اشتباه‌های رایج

- کپی کردن Hook با نام useReducer بدون بررسی Console warning، key، dependency array یا update شدن state.
- mutate کردن object یا array در state به جای ساخت copy تازه با spread، map یا filter.
- فراموش کردن تست `useReducer` با keyboard، state خالی، StrictMode و browser هدف.
