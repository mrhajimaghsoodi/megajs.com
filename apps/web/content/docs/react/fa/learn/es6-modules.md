# Moduleهای ES6

Moduleهای ES6 درباره تقسیم componentها با import و export در پروژه واقعی است. این درس بازنویسی آموزشی و مستقل از مسیر W3Schools React Tutorial است و مثال‌ها به شکل HTML کامل با React CDN و Babel نوشته شده‌اند تا در live editor اجرا شوند.

در تمرین Moduleهای ES6 فقط ظاهر UI را نبینید؛ render شدن component، تغییر state، props، warningهای Console و رفتار JSX در DOM را هم بررسی کنید.

## ایده اصلی

- `import`: component را وارد module می‌کند.
- `export`: component را در جای دیگر قابل استفاده می‌کند.
- `default export`: یک export اصلی از فایل.
- برای این موضوع، هماهنگی JSX، props، state و behavior قابل مشاهده در UI نشانه اصلی کیفیت React code است.

## مثال‌های HTML قابل اجرا با React

هر مثال یک سند کامل HTML است که react@18، react-dom@18 و @babel/standalone را از CDN load می‌کند. آن را در live editor اجرا کنید و سپس یک state، prop یا JSX branch را تغییر دهید.

## جدول syntax و کاربرد

| Syntax | کاربرد | نکته authoring |
| --- | --- | --- |
| `import` | component را وارد module می‌کند | در Moduleهای ES6 آن را با render واقعی، state خالی، interaction و Console تست کنید. |
| `export` | component را در جای دیگر قابل استفاده می‌کند | در Moduleهای ES6 آن را با render واقعی، state خالی، interaction و Console تست کنید. |
| `default export` | یک export اصلی از فایل | در Moduleهای ES6 آن را با render واقعی، state خالی، interaction و Console تست کنید. |

## اشتباه‌های رایج

- کپی کردن Moduleهای ES6 بدون بررسی Console warning، key، dependency array یا update شدن state.
- mutate کردن object یا array در state به جای ساخت copy تازه با spread، map یا filter.
- فراموش کردن تست `import` با keyboard، state خالی، StrictMode و browser هدف.
