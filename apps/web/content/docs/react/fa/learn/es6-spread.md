# Spread Operator در ES6

Spread Operator در ES6 درباره copy کردن array و object بدون mutate کردن state در React است. این درس بازنویسی آموزشی و مستقل از مسیر W3Schools React Tutorial است و مثال‌ها به شکل HTML کامل با React CDN و Babel نوشته شده‌اند تا در live editor اجرا شوند.

در تمرین Spread Operator در ES6 فقط ظاهر UI را نبینید؛ render شدن component، تغییر state، props، warningهای Console و رفتار JSX در DOM را هم بررسی کنید.

## ایده اصلی

- `...state`: propertyهای object را copy می‌کند.
- `[...items]`: valueهای array را copy می‌کند.
- `immutability`: update بدون mutate کردن state موجود.
- برای این موضوع، هماهنگی JSX، props، state و behavior قابل مشاهده در UI نشانه اصلی کیفیت React code است.

## اشتباه‌های رایج

- کپی کردن Spread Operator در ES6 بدون بررسی Console warning، key، dependency array یا update شدن state.
- mutate کردن object یا array در state به جای ساخت copy تازه با spread، map یا filter.
- فراموش کردن تست `...state` با keyboard، state خالی، StrictMode و browser هدف.
