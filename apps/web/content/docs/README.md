# Docs content (داکیومنت و مستندات)

هر تکنولوژی **پوشهٔ جدا** دارد تا مستقل ویرایش شود:

```text
content/docs/
  catalog.json          # گروه‌بندی تکنولوژی‌ها
  html/                 # مثال
    meta.json           # عنوان، توضیح، منابع، ناوبری سایدبار
    en/*.md
    fa/*.md             # فارسی — در UI با dir=rtl نمایش داده می‌شود
  react/
  nextjs/
  ...
```

## منابع ترکیبی

ساختار و ترتیب موضوعات از docs رسمی هر تکنولوژی به‌همراه MDN و W3Schools گرفته شده؛ متن‌ها بازنویسی آموزشی MEGA JS هستند (نه کپی خام).

## افزودن صفحه جدید

1. فایل `fa/my-topic.md` و `en/my-topic.md` بسازید.
2. اسلاگ را به آرایه `nav` در `meta.json` اضافه کنید.
3. Frontmatter حداقل `title` و `description` داشته باشد.
