# Introduction to Next.js

Next.js is a React framework for full-stack web apps: routing, rendering strategies, data fetching, and deployment conventions.

## App Router (modern default)

```txt
app/
  layout.tsx
  page.tsx
  docs/
    [tech]/
      page.tsx
```

- **Server Components** by default
- **File-system routing**
- **Streaming** and nested layouts

This docs section itself lives under the App Router pattern used across MEGA JS.
