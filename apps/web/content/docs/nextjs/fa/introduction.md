# مقدمه Next.js

Next.js یک فریمورک React برای اپلیکیشن‌های full-stack وب است: routing، استراتژی‌های render، واکشی داده و قراردادهای استقرار.

## App Router (پیش‌فرض مدرن)

```txt
app/
  layout.tsx
  page.tsx
  docs/
    [tech]/
      page.tsx
```

- به‌طور پیش‌فرض **Server Components**
- **مسیریابی فایل‌سیستمی**
- **Streaming** و layout تو در تو

همین بخش مستندات هم روی الگوی App Router در MEGA JS پیاده شده است.
