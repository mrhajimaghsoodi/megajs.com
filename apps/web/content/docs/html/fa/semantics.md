# معناشناسی (Semantic)

از landmarkها استفاده کنید: `header`، `nav`، `main`، `aside`، `footer`، `section`، `article`.

Screen readerها و سیستم‌های SEO به این ساختار تکیه می‌کنند — نه به نام کلاس CSS.
