# رسانه و تصویر

```html
<img src="/hero.jpg" alt="تایملاین مسیر یادگیری" width="1200" height="630" />
```

`alt` معنادار بنویسید. برای تصویر واکنش‌گرا از `<picture>` / `srcset` و برای ویدیوی اختصاصی از `<video controls>` استفاده کنید.
