# دسترس‌پذیری

- استایل focus را حذف نکنید.
- به‌جای `div` قابل کلیک، از `button` / `a` استفاده کنید.
- ARIA را فقط وقتی HTML بومی کافی نیست اضافه کنید.

اول HTML درست بنویسید — ARIA ساختار خراب را درست نمی‌کند.
