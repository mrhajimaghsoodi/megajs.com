# Type Operator با نام keyof

Type Operator با نام keyof خلاصه‌ای از ساختار رسمی typescriptlang.org/docs است. تمرکز آن روی ساخت union از keyهای property و استفاده از آن‌ها در constraintهای generic است و هدف آن کمک به author برای خواندن Handbook و Reference بدون تبدیل صفحه به dump کامل مستندات است.

## چگونه متن رسمی را بخوانیم

در TypeScript Docs، بخش Get Started مسیر ورود را می‌سازد، Handbook مفاهیم روزمره و type-level را توضیح می‌دهد، Reference رفتار module و compiler را دقیق‌تر می‌کند، و Project Configuration تنظیمات production را پوشش می‌دهد.
